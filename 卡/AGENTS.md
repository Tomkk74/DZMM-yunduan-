## 速记

| | |
| --- | --- |
| 成品目录 | `卡/<卡名>/` |
| 规范目录 | 仓库根 `_模板/`（勿往里写角色正文） |
| 控制台 | http://127.0.0.1:8788 → 角色卡 → 本地写卡 |
| 游戏工程 | 无关时不要改 `publish/` |

**AI 写卡参考顺序**：brief → name/tags → description → personality → scenario → system_prompt → creator_notes → 世界书（含常驻「玩家设定」）→ 开场对话 → 图/音色 → 自检。详见 `_模板/填写顺序.md`。

**试玩**：卡「保存到云端」成为正式卡后，控制台舞台栏可点「试玩」——写卡区切为平台对话试玩（模型 / 深度思考 / 回复长度 / 账号预设）。详见 `docs/character-card-local-api.md`「试玩」。
