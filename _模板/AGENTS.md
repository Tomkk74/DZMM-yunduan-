# 角色卡 · Agent 冷启动（无记忆入口）

你正在协助用户在本仓库写 **DZMM 角色卡**。  
若对话没有历史：以本目录为准，不要猜测另一套格式。

## 立即执行

1. 读完本文件。  
2. 读 `填写顺序.md`（**强制顺序**）。  
3. 读 `写作规范.md`（平台各框怎么写）。  
4. 需要文件树时对照 `空白卡结构/`。  
5. 在 `卡/<卡名>/` **写入文件**（不是只在聊天里生成长文）。

用户若说「根据模板规范创作 XXX」：卡名=XXX，创意进 `brief.txt`，然后按 `填写顺序.md` 从第 0 步做到第 5 步。

## 硬约束

- **规范来源**：`写作规范.md`（对齐官网 studio 填写框）。字段用途不要串台。  
- **占位符**：进模型字段优先 `{{user}}` / `{{char}}`（详见 `写作规范.md`），勿把玩家名写死进系统指令与世界书。  
- **玩家设定**：无独立 user 栏；必须在世界书写一条**常驻**「玩家设定」（建议 `entries/002/`），见 `写作规范.md`。  
- **落盘位置**：`卡/<卡名>/`。禁止修改仓库根目录 `_模板/`。  
- **不要**调用平台 AI 写卡；**不要**改 `publish/` 等游戏工程（除非用户明确要求游戏卡）。  
- **优先改 `.txt`**；`card.json` 可由控制台同步重写，不必手搓完整 JSON。  
- 发布/隐藏/删云端卡：未要求不要做。

## 和本机控制台的关系

- 控制台默认：http://127.0.0.1:8788 → 角色卡 → 本地写卡。  
- 用户可先在网页「创建卡夹」；你也可直接建 `卡/<卡名>/` 文件。  
- 文件变更后网页约 700ms 内同步；上云用控制台按钮，上架去官网。

## 字段 → 文件（速查）

| 平台 | 本地 |
| --- | --- |
| 角色名 | `name.txt` |
| 详细描述 | `description.txt` |
| 性格 | `personality.txt` |
| 场景 | `scenario.txt` |
| 系统指令 | `system_prompt.txt` |
| 角色卡介绍（AI 不可见） | `creator_notes.txt` |
| 标签 | `tags.txt` |
| 世界书 | `character_book/`（含常驻「玩家设定」） |
| 玩家设定（约定） | `character_book/entries/002/` 常驻条，不是独立平台字段 |
| 开场对话 | `chat_history.json` + `first_mes.txt` |
| 建议回复 | `suggested_replies.txt` |
| 头像/图库 | `avatar_url.txt` `assets/` `image_info.json` |

## 写卡顺序（摘要）

完整说明见 `填写顺序.md`：

0. 建夹 + `brief.txt`  
1. name → tags → description → personality → scenario → system_prompt → creator_notes  
2. 世界书（001 世界观常驻 → 002 玩家设定常驻 → 003+ 触发）  
3. 开场对话 + first_mes + 建议回复  
4. 图/音色（可缺）  
5. 自检并汇报  

## 完成后回复用户

简短说明：卡路径、按顺序已写的文件、缺什么（如图）、是否需要他在控制台保存到云端。
