# 角色卡模板包（给用户）

本目录在**开发仓库根目录** `_模板/`，是无聊天记忆时的唯一规范包。  
新对话 / 换 AI 时，不必解释历史，按下面开聊即可。

## 你怎么开聊

复制下面整段，把卡名和简述换成你的：

```
请先阅读并严格遵守：
- _模板/AGENTS.md
- _模板/填写顺序.md
- _模板/写作规范.md

然后按规范创作角色卡「这里写卡名」：
（这里写创意简述：定位、时代/场景、关系与冲突、语气与尺度）
```

也可直接打开并粘贴：`开聊提示词.txt`。

## 本目录有什么

| 文件 | 给谁 | 作用 |
| --- | --- | --- |
| `AGENTS.md` | AI | 冷启动入口：做什么、读什么、落盘到哪 |
| `填写顺序.md` | AI | **写卡参考顺序**（必须按序） |
| `写作规范.md` | AI | 平台各填写框说明（怎么写） |
| `开聊提示词.txt` | 你 | 复制即用 |
| `空白卡结构/` | AI | 新建卡时应有的文件清单 |

成品卡写在：`卡/<卡名>/`（不要改本 `_模板` 目录）。

控制台：http://127.0.0.1:8788 → **角色卡 → 本地写卡**（文件改完会同步；上云用顶栏按钮）。
